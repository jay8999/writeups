# Cybersecurity Writeups & Lab Notes

A personal collection of technical writeups, vulnerability analyses, and exploit breakdowns from platforms like TryHackMe and PortSwigger Web Security Academy. This repository serves as a structured archive of my hands-on offensive security learning, covering everything from web application vulnerabilities to system privilege escalation.

# Directory Structure

/Web-Exploitation - Walkthroughs focusing on OWASP Top 10 vulnerabilities, injection flaws, and client-side attacks.

/Privilege-Escalation - Notes and enumeration techniques for elevating local access on Linux and Windows systems.

/Network-Penetration - Full-box walkthroughs detailing initial enumeration, exploitation, and post-exploitation workflows.

# Featured Writeups

Format Breakdown

Every writeup in this repository follows a consistent three-part structure to ensure clarity and actionable understanding:

Reconnaissance & Enumeration: How the target was discovered, what ports/services were open, and how vulnerabilities were identified.

Exploitation: Step-by-step mechanics of how the vulnerability was leveraged to gain access or manipulate application logic.

Remediation: Secure coding practices or configuration changes required to patch the flaw.

# Disclaimer: All writeups and technical notes contained in this repository are performed on authorized, isolated lab environments (such as TryHackMe and PortSwigger academies) strictly for educational purposes.
